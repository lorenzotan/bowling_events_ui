# Bowling Events UI

## Description
Mobile/Web UI for the Bowling Events mobile app using the [Ionic Framework](https://ionicframework.com/docs/vue/overview) with [Vue](https://vuejs.org/guide/introduction.html).

## Getting Started
```
# Build Docker image
$ docker build -t bowl:ui .

# Run Docker Container using Docker Compose
$ docker compose up -d
```
Navigate to view Ionic app.
[http://localhost:8100](http://localhost:8100)
